# PD 评估中的加速卡连通性检查

计算网络只声明部署使用哪个卡间网络，不保证其中任意两张卡都互通。
两端卡号相同也不能证明可达。

对于跨节点、通过 HCCL 传输 KV 的 PD 部署，评估和创建共用卡对检查。
检查从所选计算网络保留的已完成卡测试中，为每个卡对取最近一条有效结果。
结果须在 24 小时内，且两端节点、卡口及当前 RoCE 或 HCCS 地址均匹配。
范围更窄的测试、工具失败和进行中的重测不会覆盖该卡对已有的有效结果。
卡 ping 包含应答，现有测试因此只存每个节点对的一次往返探测；检查接受任一存储方向。
主机 TCP、主机 RDMA 测试不能作为加速卡口互通的证据。

| 消息码 | 类型 | 含义 |
| --- | --- | --- |
| `PD_CARD_NETWORK_BLOCKED` | 错误 | Prefill 和 Decode 各有一个单节点实例，各固定一张卡，且跨节点卡对实测不通。评估返回 `ok: false`，创建返回 HTTP 400。 |
| `PD_CARD_NETWORK_UNREACHABLE` | 告警 | 其他布局中存在实测不通的卡对，如多卡、多实例或有 follower 的布局。 |
| `PD_CARD_NETWORK_UNTESTED` | 告警 | 缺少完整有效证据，如自动选卡、没有有效的卡对结果、地址变化或测试超过 24 小时。 |

消息给出网络、所选卡对，以及最近有效结果显示互通的其他卡对（最多八组）。
这里的互通只指网络可达，卡是否空闲仍由放置检查判断。
告警允许提交。实际推理能否完成 KV 交接仍需在引擎启动后验证。
建议固定所需卡号，并在部署前运行卡矩阵测试。

连通性检查不能解释所有本地 Mooncake 初始化失败，也不能代替引擎启动验证。
