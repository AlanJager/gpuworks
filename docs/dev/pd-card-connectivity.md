# PD 评估中的加速卡连通性检查

计算网络只声明部署使用哪个卡间网络，不保证其中任意两张卡都互通。
两端卡号相同也不能证明可达。

对于跨节点、通过 HCCL 传输 KV 的 PD 部署，评估会读取所选计算网络最近一次卡测试，
匹配指定的 prefill、decode 卡口及当前 RoCE 或 HCCS 地址。
卡 ping 包含应答，现有测试因此只存每个节点对的一次往返探测；检查接受任一存储方向。
主机 TCP、主机 RDMA 测试不能作为加速卡口互通的证据。

| 告警 | 含义 |
| --- | --- |
| `PD_CARD_NETWORK_UNREACHABLE` | 匹配所选端口的探测记录为不可达。 |
| `PD_CARD_NETWORK_UNTESTED` | 缺少完整有效证据，包括自动选卡、缺少卡对记录、工具失败、地址变化或测试超过 24 小时。 |

告警给出网络、所选卡对，以及同一次测试中已验证互通的卡对（最多八组）。
这里的互通只指网络可达，卡是否空闲仍由放置检查判断。
告警不阻止提交：`ok: true` 表示配置被接受，不保证网络或推理引擎必然启动成功。
建议固定所需卡号，并在部署前运行卡矩阵测试。

连通性检查不能解释所有本地 Mooncake 初始化失败，也不能代替引擎启动验证。
