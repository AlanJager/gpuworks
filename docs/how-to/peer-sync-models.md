# 在节点之间同步模型和镜像

本文说明怎样复制已有的模型或推理镜像，并检查同步结果。

**适用场景**：已有完整副本，希望避免重复公网下载；或排查 `NO_STORAGE_PATH`、直连测试不通、停在 `download_required` 等问题。本页的手动复制不受同步组限制。

**前置条件**：

- 来源持有完整副本（本地模型为 `present` 或 `registered`，共享存储中的模型为 `present`，镜像已存在于运行时）。目标模型存储可写且适用于执行节点。
- **跨节点直传**：源节点和目标节点都[在线](connect-nodes.md)，且有共同的存储同步网络，或都允许管理网承担存储同步，见[配置节点网络](configure-networks.md)。
- **同节点复制模型**：执行节点在线，能读取源存储并写入目标存储，无需配置节点间的存储同步网络。
- 自动复制只发生在同组节点之间，分组与限速见[配置镜像拉取](configure-pull-settings.md#同步组)。
- 模型的注册与其他获取方式见[下载、缓存和节点间同步模型](download-and-sync-models.md)。

副本启动时，本机没有而同组在线节点持有的模型或镜像可**自动复制**，失败后改为拉取或下载。下面的**手动复制**使用你确认的源节点；源失效时不会静默换节点或改走公网。

## 同步一个模型或镜像

### 模型

1. 在**模型**页对应行点击**复制到…**，在**源**中确认持有完整副本的本地存储与节点。下载完成和登记已有路径的完整副本都可使用。
2. 选择可写的目标本地存储与目标节点。按需填写限速，单位 MiB/s；留空或 0 表示不限速。
3. 点击**开始复制**。此弹窗没有独立的**测试直连**步骤，复制时会建立直连；在模型详情查看目标节点进度，完成后确认状态为 `present`。

**复制到…** 也支持共享存储作为源或目标。选择共享目标时不需要指定目标节点，平台会选择执行节点；能在同一节点读写时直接拷贝，否则使用节点间传输。不要把共享存储复制都当作两台节点之间的直连。

### 镜像

1. 在镜像详情的目标节点行发起同步，确认源节点。
2. 点击**测试直连**。通过后才允许同步；测试只验证 TLS 与令牌握手，不传镜像文件，也不创建同步任务记录；实际同步仍会重新握手。
3. 按需填写限速，然后发起同步。在目标节点行查看进度，确认镜像已导入并显示为已有。

每次复制的限速独立设置，API 字段 `rate_limit_kib_s` 使用 KiB/s。多目标各自限速；任务结束后清除活动限速，失败记录保留上次限速供重试。

## 走哪张网

两个节点之间用哪张网由 server 按节点对选定，规则见[配置节点网络](configure-networks.md)：

- 两端共同的存储同步网络优先；否则两端都允许管理网承担存储同步时走管理网。
- 目标只在该网络的地址上接收，源节点从本端在该网络的地址发起，并按一次性证书指纹校验。
- 两端没有可用的共同网络时报 `NO_STORAGE_PATH`；自动复制会跳过该源，副本改为自己拉取或下载；手动指定该源时报该错误。镜像可先用**测试直连**检查；模型以复制任务的连接结果为准。
- 自动复制时直连失败（约 10 秒）的节点对，server 在内存里冷却 3 小时，期间不再尝试复制；重启 server 清空冷却。

## 镜像在不同运行时之间同步

Docker、nerdctl 与 runveil 节点之间镜像可互为源和目标。runveil 导出的是 OCI 布局加 `manifest.json` 的归档（与 Docker 29 `docker save` 同形），层按 registry 原样的压缩字节发送，manifest digest 在两端一致；它只能发送自身镜像存储里完整的镜像，旧 udocker CLI 登记的镜像需重新拉取或导入。

## 重试与恢复

- 源节点离线或副本不完整时，任务会失败或停在 `download_required`。恢复原源后可重试；要换源，重新选择完整副本发起复制。重试沿用失败记录里的源节点和上次限速，后台不会自动重试已失败的手动选源任务。
- 模型同步可在目标节点行取消；取消请求会停止接收，若页面提示停止未确认，先处理该任务，不要把部分文件登记为完整副本。镜像取消停止的是目标接收与运行时导入（Docker 上为 `docker load`），不能将其等同于模型下载续传。
- 镜像同步在 server 或节点重连后，若该传输两分钟内仍有进度则沿用原传输，否则用原源节点和限速从零重新开始。
- 公网下载失败后，若有在线节点持有完整副本，仍可再手动走一次节点间同步，不会永久卡在失败状态。

节点间传输由目标 agent 提供一次性 TLS 接收端，源 agent 直连发送，server 不中转文件。模型完成后重新校验文件清单；镜像以目标运行时完成导入并确认镜像存在为准。
