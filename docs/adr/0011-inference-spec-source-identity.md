# ADR 0011: 同一原始模型的档位按来源隔离身份

日期: 2026-09-01 · 状态: 已接受

内置目录升级与用户扩展必须能够落在同一个原始模型下，而不能让同名档位互相覆盖。档位身份因此固定为 `(original_model_id, source, name)`，其中 source 只有 `upstream` 与 `user`；内置对账只更新或删除 upstream 档位，user 档位及其内容寻址资产包保持不变。部署、预览和 Playground 都保存并传递档位来源；同名跨来源且调用方未指定来源时必须报歧义，不能依赖数据库顺序。原始模型的规范元数据与说明在 upstream 条目存在时仍由内置目录拥有，用户扩展只增加 user 档位；如果内置目录移除该原始模型但仍有 user 档位，条目才转为用户所有。

这个选择避免了两种更粗的边界：按 `model_id` 隔离会强迫用户为了增加一种权重而伪造新的原始模型，按引擎整组覆盖则会在更新一个档位时删除同引擎的其他用户档位。代价是同名档位的显式选择必须多携带一个 source 字段，但它换来了可预测的升级行为和精确的资产归属。
