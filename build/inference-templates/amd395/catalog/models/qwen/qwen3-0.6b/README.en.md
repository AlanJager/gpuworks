# Historical acceptance: Qwen3-0.6B · AMD395 / gfx1151

**This page records the retired AMD395 host's historical r2/r5 acceptance only. It does not describe the model revision or weight size of a package generated today.** Current source files are launch overlays: `prepare_import.py` derives model configuration and BF16 weight facts from the explicitly selected current seed spec. Those revisions and sizes can differ from the historical values below and require fresh hardware acceptance. Follow the [current package instructions](../../../../README.md) for source selection, explicit image mapping and exact image-ID verification.

The historical profile used official `Qwen/Qwen3-0.6B` revision `c1899de289a04d12100db370d81485cdf75e47ca`. Its safetensors index identified one `model.safetensors` file totaling 1,503,300,328 bytes; tokenizer and configuration files were excluded. Weights were fetched separately and were not included in either inference image. The historical weight file had LFS SHA-256 `f47f71177f32bcd101b7573ec9171e6a57f4f4d31148d38e382306f42996874b`. These numbers identify the old accepted input, not an expected value for the current materializer.

The vLLM r2 run exercised single-GPU BF16 with TP1, 4096-token context, one sequence, eager mode and a 0.25 GPU-memory fraction. The SGLang r5 run exercised BF16, context 4096 and four running requests, with a 0.40 static-memory fraction, Triton attention, CUDA graphs disabled, metrics enabled, chunked prefill 1024 and 16,384 total tokens. SGLang passed eight short text requests on that host, four each at concurrency one and four, using historical image `sha256:c8de20ed7d138f6e3442c5995ad71a6810d097cb010032fbaec27106fef4cc1d`. The older r2 SGLang metadata was retained for rollback. These were model-specific smoke settings, not global engine defaults or acceptance of later seed revisions.

The historical recipes required one AMD GPU, architecture ID `gfx1151` and an AMD395-family name. The fallback name `AMD GPU 0x1586 (gfx1151)` identified an architecture family, not an exact Ryzen 395 SKU. Available UMA depended on host configuration; 128 GB of system memory did not establish 128 GB of GPU-allocatable memory. The component checks covered engine import, dependency consistency and PyTorch's compiled gfx1151 target; they did not prove GPU execution by themselves.

The recorded runs covered limited BF16 text startup and chat. They did not establish image input, broad answer quality, sustained performance, long contexts, memory-limit behavior or multi-GPU isolation. Importing metadata does not transfer image layers or validate a new seed revision.
