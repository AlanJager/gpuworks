# 单机浏览器 E2E 可执行范围

本表按页面、API 与运行边界盘点候选维度；“可做”只说明环境能力，不代表已实现或已覆盖。
规范见 [主规范](browser-e2e-testing-standard.md)和[组件检查清单](browser-e2e-component-checklists.md)。
每条实际结果以 `secrets/e2e/<runId>/report.json` 为准，绑定源码、脚本与二进制摘要；不按页面数量计算通过率。

## 环境能力边界

| 环境 | 可承载的验证 | 执行前提 |
|---|---|---|
| 独立 server/SQLite + Chrome | 控制面与浏览器持久化 | 构建工具、Python Playwright、系统 Chrome；独立数据库与端口 |
| 上述环境 + 本地 HTTP/协议 fixture | 外部来源、代理和协议交互 | 可审计、可失败、可清理的真实协议服务 |
| 真实 agent / 隔离容器 | 文件、镜像、进程与容器执行 | 显式节点、独立状态和文件目录；不能在共享 daemon 上无范围操作 |
| GPU / 多宿主 / 外部账号 | 设备效果、真实推理、跨机通信 | 对应硬件、驱动、拓扑、授权及空闲资源 |

当前资源可用性须每次预检；本表不保存开发机的历史探测快照。已有 case 的绑定、所需证据和缺口
只维护在 [coverage/](coverage/)，操作与断言见其 `test_file`。通用执行与产物约定见
[README](README.md)，远端专用准备见 [runner](remote_runtime_acceptance.py) 文件头。
配置登记、真实文件/容器执行与 GPU 行为分别记账；不能把一个环境的结果算到另一环境。

## 仅需 server 的候选维度

以下是按环境分类的候选维度，不维护实现状态或通过数。新增 case 后在对应覆盖清单登记已实现范围与剩余缺口，不在本表追加验收正文。

| 页面 | 候选维度 | 必需证据与限制 |
|---|---|---|
| 登录 / 导航 | 会话生命周期、深链、过期与主体隔离 | 登录请求、会话生命周期、页面与API拒绝；产品没有修改密码UI，不写虚构入口 |
| 推理模板 | 目录包身份、规格隔离、引用删除与并发编辑 | 精确包/spec身份、原包不被克隆编辑覆盖；不证明部署可运行 |
| 推理模板 | YAML/schema 字段边界、重复导入与错误原子性 | 校验/错误不产生部分修改；真实服务端校验 |
| 镜像目录 | 系列/版本字段、启停、引用删除与权限 | 版本 `/images/{versionId}` 与系列 `/image-series/{seriesId}` 分别验证；不证明pull |
| API Key | 平台write、30/90/365天选项、过期边界、不同用户归属隔离 | 每个option独立请求/回读/鉴权；时间边界用受控基准 |
| 网络 | 各真实类型/角色、组合搜索、10/30/100条、分页、被引用删除 | 按API支持枚举；有节点或部署引用时再加入运行时验证 |
| 存储 | shared_dir/nfs/nfs_cache各表单的字段负例、条件字段、无在线节点拒绝 | 非local类型创建强制节点试挂，成功登记和资源选择闭环归agent lane |
| 设置 / 部署策略 | 启动超时上下界、非法值、取消/保存、刷新 | 只覆盖设置合同；worker实际超时需agent |
| 设置 / SSH密钥 | 导入测试私钥、拒绝损坏格式、轮换取消与确认、指纹/公钥回读 | 私钥不入trace；真实SSH授权验证需本地sshd |
| 节点 | 创建节点定义、名称/标签修改、搜索/筛选、取消删除/删除 | 节点注册对象不等于在线；上线/重连另列 |
| 概览 / 监控 | 自有节点/部署库存数量、筛选、空态、时间与URL回填 | 不把空图或人工库存当真实GPU指标 |
| 日志 | server筛选枚举、分页、时间边界与错误恢复 | agent/container采集另需真实agent/容器；范围按覆盖清单逐项登记 |

## 单机增加可审计外部 fixture 后可做

本地 fixture 只能替代产品外部依赖；server、SQLite、调度和被测UI操作仍真实。

| 页面 | 候选维度 | 额外依赖与结论边界 |
|---|---|---|
| 模型管理 | 来源元数据、规范化、目录与配置兼容性 | 本地HTTP目录含tiny config/index；无需GPU，不证明权重下载至节点 |
| 模型管理 | 来源不可达、损坏或变更的错误原子性与恢复 | 可控HTTP目录；真实server在注册时重新读取 |
| 评测 | 外部端点探测、小规模grid、报告与统计 | 可审计OpenAI fixture，核对请求数/usage/错误；是真实评测执行，但不是GPU性能 |
| 评测 | 取消、连接终止、任务结束与报告一致性 | fixture支持流式、取消和错误，不能每次无条件成功 |
| 设置 / 代理 | 代理/重写配置与上游实际路径 | 本地HTTP/proxy fixture；仅设置保存不足以证明生效 |
| AI助手 | 兼容服务配置、工具读取、取消与错误恢复 | 可审计LLM fixture；核对工具与脱敏，不证明真实厂商模型质量 |

## 需要真实本机 agent 或隔离容器的操作

| 页面 | 可增加的主线 | 前提 |
|---|---|---|
| 节点 | 在线/断线重连、换token后重新接入、doctor、host终端输入输出/退出释放 | 独立真实agent state、WS会话与本机进程 |
| 模型管理 | tiny模型下载/取消/重试、文件清单/hash、删除文件 | 真实agent + 本地HTTP仓库与独立文件目录 |
| 存储 | shared_dir/nfs/nfs_cache试挂并创建、本地路径读写、挂载生效、禁用后新增部署限制、引用保护 | 非local创建必须通过真实agent探测；NFS还需隔离NFS服务与权限 |
| 网络 | 节点绑定/解绑、地址探测、服务地址选择 | 真实agent及可控接口/地址，不能拿假GPU事实替代网络 |
| 监控 / 日志 | CPU/内存采集、agent/实例日志marker、实时流与取消 | 真实agent；实例日志需独立容器 |
| 镜像目录 | 导入OCI、拉取/取消/重试、实际digest与清理 | 独立Docker daemon和本地OCI fixture |
| 部署 / 实例 | fake-engine创建/启动/停止/重部署/删除，挂载与日志 | 真实agent + 独立Docker + tiny model；只证明容器协议与生命周期 |
| Playground | 网关/会话两条调用链、流式结束、取消、错误、Markdown/HTML预览 | 上述真实容器/网关；fake-engine不证明真实模型推理 |
| 终端 | host/container键盘交互、断连、空闲关闭、禁用与并发限制 | 真实pty；container路径需真实容器 |

真实探卡/驱动、dGPU限额隔离、sleep/wake显存释放、推理性能、跨宿主NCCL/RDMA、多机推理、
付费云租机和厂商兼容仍需对应硬件/账号/拓扑，不能标为当前单机已验证。
