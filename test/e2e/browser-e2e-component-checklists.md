# GPUWorks 浏览器 E2E 组件检查清单

本清单是[浏览器 E2E 测试规范](browser-e2e-testing-standard.md)的逐项执行版，适用于 GPUWorks
当前真实页面和组件。每个编号是一项独立检查要求，不代表已有自动化或已经通过。

每个页面先列出实际组件、字段和选项，再把适用编号关联到用例与本次执行证据。
不支持的能力写 `N/A + 产品原因`；已支持但缺用例、夹具或证据的项目必须登记缺口，不能写 N/A。
共享组件测试验证通用行为，消费页面仍需验证实际请求、持久化和运行时接线。
状态和覆盖率统计沿用主规范；不得用本清单的条目数量充当通过数。
盘点包括所有可达搜索框、快捷标签/chip、下拉框和条件控件，逐项记录请求语义及组合关系；
相似文案或相同组件类型不能合并覆盖。已有 case 通过只代表其明确执行的子集。

清单是**写前设计输入**，不是事后勾表：每个页面先产出“组件盘点 → 适用项 → 具体断言”的映射，再写
用例。绑定项必须能反查到 case 中的步骤、字段、单元格或请求体；只凭标题相似绑定（任何确认算 12.7、
任何数字算 17.1、任何持久化算 1.14 等）按未覆盖处理。适用但本次不做的项逐项写 `MISSING`，不能用一个
段落吞掉整节。

## 1. 表单整体：创建与编辑

1. **字段盘点**：逐个登记标签、组件类型、必填性、默认值、单位、合法范围、条件显示、请求字段和持久化字段。
2. **首次打开**：默认值正确；编辑时回填已保存值；异步加载结束前不能提交不完整数据；secret 不回显。
3. **必填校验**：每个必填字段分别输入空字符串和纯空白，错误定位到该字段，且没有 mutation 请求。
4. **字段边界**：按后续组件清单逐字段执行最小、最大、越界、非法格式等适用场景；不虚构产品没有的上限。
5. **枚举穷举**：每个实际可选项单独选择，验证选中态、精确提交值、保存回读及适用运行时效果。
6. **条件字段**：切换控制项，验证显隐、首次默认值、隐藏值的提交规则、重新显示后的保留或重置规则。
7. **最小创建**：仅填写必填项，通过 UI 提交，验证 method/path/body、响应、列表与详情，并刷新和独立 GET 回读。
8. **完整创建**：填写所有适用可选项，逐字段验证持久化；可选项省略时另外验证后端默认值。
9. **防重复提交**：在确定的提交中状态重复点击或按 Enter，只产生一次创建/更新，不生成重复资源。
10. **失败恢复**：真实服务端拒绝时保留草稿和弹窗，显示可操作原因；修正或重试后成功，失败时没有部分写入。
11. **取消退出**：分别取消、关闭、Esc；不发送 mutation，原数据保持不变；未保存提示按产品合同验证。
12. **编辑变更**：分别覆盖 A→B、开→关→开、有值→空、绑定 A→B→无；仅改一个字段时其他字段保持原值。
13. **并发与失效**：编辑期间资源被删除或被另一个会话更新，按真实 API 合同验证冲突或最后写入结果及恢复入口。
14. **持久化与运行时**：重进页面与独立查询一致；涉及部署、调度、鉴权、挂载等配置时继续验证 agent/workload 或真实调用。
15. **键盘与布局**：Tab 可达、Enter 不误提交、错误可感知，1440×900 下字段与底部操作可达且不重叠。

## 2. 文本输入与多行文本

1. 检查标签、说明、placeholder、默认值及只读/禁用状态；placeholder 不能代替可访问标签。 默认值必须断言控件实际值（如 `input_value()`），不能以 placeholder 或提示文字作为证据；同时核对未手改时提交的字段值或明确的后端默认语义。
2. 分别验证空、纯空白、前后空格，明确 trim 与保留空白的字段差异，并检查最终请求和回读值。
3. 有长度合同的字段分别验证最短、最短减一、最长、最长加一；明确按字符还是字节计数。
4. 输入中文、英文、数字、标点、换行及产品禁止字符，验证接受或具体错误，不能以浏览器输入成功代替保存成功。
5. 对名称唯一性等服务端约束构造真实冲突；失败后原值保留，修改后错误消失且可重新提交。
6. 验证文本粘贴、清空、键盘编辑；多行内容换行在保存与重进后保持合同语义。
7. 在列表、详情和预览显示带 HTML 字符的文本，确认按该字段合同转义，不能执行非预期脚本。

## 3. 数字输入、Slider 与 Stepper

1. 检查默认值、单位、step、上下限；区分 GPU 数量、MiB/GiB、百分比、时间与并发数量。
2. 分别验证 0、最小、最大、上下越界；负数、小数、空值和非数字按真实字段合同接受或拒绝。
3. 使用键盘、加减按钮和滑块实际改变值；有联动输入框时值与限制一致。
4. 检查 JSON 数值类型，不得把字符串、空字符串、null、0 和省略混为一谈。
5. 保存后刷新和 GET 回读单位换算与精度；运行时按保存值执行，不能只比较格式化展示文本。
6. 对服务端字典提供的范围与 step 验证前后端一致，拒绝后原配置保持不变。

## 4. URL、地址与路径输入

1. 检查协议、host、端口、path、query、尾斜杠及默认值；只要求当前字段支持的地址形态。
2. 验证非法协议、缺 host、非法端口、重复路径前缀和空值，检查具体错误与是否发送请求。
3. 分别验证用户输入值、规范化请求值和保存值，不能静默丢失有效端口、路径或 query。
4. 节点地址、镜像引用、模型目录和挂载路径使用各自合同，不能把文件路径套用 HTTP URL 校验。
5. 切换来源或重开编辑框后，用户人工覆盖值按合同保留，不能被自动默认值悄悄替换。
6. 页面承诺可直接访问或执行的地址，按第 21 节复制后从用户可访问的网络边界真实调用。

## 5. Select、Combobox、Radio 与 Segmented

1. 验证默认项、可见标签、选中态与禁用原因，枚举本次页面实际显示的所有选项。
2. 每个可选项独立执行选择→请求→保存→刷新回读；只检查 option 存在不算该项覆盖。
3. 有搜索能力时验证完整/部分搜索、无结果、清空搜索及恢复候选。
4. 有清空能力时验证清空；没有时验证产品规定的返回默认路径，不添加不存在的清空操作。
5. 切换选项触发的区域、默认值及隐藏字段提交规则正确；切回原选项后没有错误的陈旧值。
6. 验证键盘打开、移动、选择和关闭；菜单 portal 关闭后焦点回到合理触发位置。
7. 异步选项加载失败、重试或选项失效时，不得提交看似有效但实际不存在的值。

## 6. Checkbox、Switch 与三态参数

1. 验证默认态、可访问名称、禁用态及原因。
2. 分别完成关→开、开→关并检查精确布尔请求值及刷新回读。
3. 三态引擎参数分别验证“由引擎决定”、显式 true、显式 false，确认省略与显式 false 不混用。
4. 控制项影响其他字段时验证显隐、禁用、默认值与陈旧值提交规则。
5. 保存失败时按产品合同恢复原态或保留待保存态，不能显示成功而后端未改变。
6. 涉及运行时能力的开关通过真实 workload/调用观察效果；disabled 不一律等同于现有资源立即不可读。

## 7. Secret、密码与一次性令牌

1. 按字段合同验证必填/可选、空值、纯空白、掩码及显隐操作，不能假定所有凭据必填。
2. 编辑留空分别按“不修改”或“清空”的真实合同验证，不得依靠 UI 掩码猜测后端值。
3. 创建返回的一次性明文只在允许的时机显示；关闭、刷新、重新查询后不能回显。
4. 使用新凭据完成一次实际允许的操作；错误、撤销、权限范围及适用过期场景分别验证。
5. 区分管理会话、`gwp_` 平台令牌与 `gw-` 推理 Key；推理 Key 当前没有过期字段，不编造过期控件。
6. 检查普通 GET、错误、日志和下载不泄露明文；trace、截图、剪贴板采集与报告须在采集阶段保护 secret。
7. 密码修改后验证管理会话撤销；平台令牌按其独立生命周期验证，不能误断言随密码修改一起撤销。

## 8. 资源选择器与多选绑定

1. 候选展示可读名称和必要辨识信息，通过真实 selector API 选择，不能要求用户输入内部 ID。
2. 验证搜索、无结果、清空搜索、候选加载失败与重试，精确检查 query 和候选集合。
3. 验证选中值回填；候选因新搜索不在当前集合时，已选资源名称仍正确。
4. 分别绑定 A、换绑 B、移除/清空，刷新查询正向关系；有反向查询能力时同时验证旧关系已解除。
5. 多选添加或删除一项不影响其他项；最大选择数和重复选择按合同验证。
6. 禁用、离线、不兼容、已删除或无权限候选有正确提示且不可错误提交；提交时失效要由真实后端拒绝。
7. 大集合目标仍可找到：当前 NodePicker 搜索返回单页，验证第 51 条可通过搜索找到，不虚构分页按钮。
8. EligibleNodePicker 分别覆盖在线、硬件适配和多机地址条件；影响调度/挂载的选择继续验证真实落点。

## 9. 时间范围与自动跟随

1. 每个实际可见 preset 分别验证选中态、from/to 或对应参数、响应与已知记录集合，不能只测一个代表项。
2. 自定义范围验证开始/结束、合法范围、倒置、产品上限及精度边界；编辑尚未确认时不触发提交查询。
3. 分别确认与取消自定义范围，验证确认后查询更新、取消后仍使用原范围。
4. 使用明确服务端时间和边界记录检查包含关系；当前指标/日志为两端包含，不能照搬 Router 的半开区间。
5. 验证 UI 时区到请求时间的转换、Unix 毫秒与 duration 单位；不能把 `24h` 写成接口不支持的 `1d`。
6. 验证 quick range 的滑动、fixed custom 的固定窗口、live/follow 的开关及监控 URL range/follow 回填。
7. retention 提示与硬性非法范围分别验证；超过保留期的警告不能被测试写成必然禁止查询。
8. 时间切换、请求乱序或刷新后，图表/日志/总数均对应最终选中范围，没有旧响应覆盖新结果。

## 10. 表格、列表与分页

1. 分别构造 loading、空数据、失败和有数据，验证完整状态、总数、重试和恢复后的行集合。
2. 搜索覆盖完整、部分、不存在、特殊字符、清空及大小写/空白合同，检查 query、命中和排除行。
3. 每个实际筛选项独立执行；组合至少两个条件，覆盖各自有结果但交集为空，检查参数与集合。
4. 每个可排序列验证升降序和相同值稳定顺序，确保先按产品合同排序再分页。
5. 独立切换全部实际 page-size；ResourceTable 默认 20，可选 10/20/50/100，以页面配置为准。
6. 验证首页、上一页、下一页、末页及边界禁用；逐页收集稳定 ID，无重复无遗漏，返回顺序一致。
7. 搜索、筛选、page-size 或数据变化后保持合法页；删除末页最后一条后总数、页码和行集合正确。
8. 分别准备总量 10、30、100 的真实归属数据，验证跨页查询与操作；page-size 选项不能代替总量证据。
9. 逐行按唯一业务文本定位操作，验证详情/编辑/诊断在当前视口打开；不依赖自动滚动掩盖页面问题。
10. 修改后手动刷新与后台更新按合同保留筛选；轮询不能覆盖未保存草稿或让已删除对象重新出现。
11. 有分组/汇总时验证已知 2+1 分组、合计、切换及筛选联动；不同投影不能跨维度相加。
12. 允许的表格内部横向滚动与页面整体溢出分开检查，固定操作列仍可达。
13. 按主规范的组合查询合同，逐条验证相互影响的控件路径：同时命中、单项命中、交集为空、
    叠加/替换/移除恢复及适用的操作顺序；从 fixture 事实推导准确集合，不复用产品查询构造生成 expected。

## 11. 表格列偏好与批量选择

1. 拖动列宽，验证最小宽度、内容布局及刷新后回读；这是本地偏好，不要求数据库写入。
2. 分别隐藏、显示、调整顺序和重置列，验证每一步实际布局与刷新持久性。
3. 名称/操作固定列不可按禁止的方式隐藏或移动；旧版本未知列偏好安全回退。
4. 不同 `tableId` 的偏好相互隔离，同表偏好按产品合同复用。
5. 选中单行、多行、取消和全选，明确全选作用于当前页还是全部筛选结果。
6. 批量集合混合可操作、不可操作、失效及无权限资源，逐项验证实际结果与失败原因。
7. 翻页、过滤、刷新和批量失败后选择集合按合同保留或清空，不能误操作已不可见的陈旧目标。

## 12. Dialog、Drawer 与确认操作

1. 从真实页面入口打开，验证角色、可访问名称、业务组件种类与首个步骤，防止误打开另一个正常组件。
2. 打开即检查容器和关键操作在当前视口；1440×900 下标题、说明、内容与底部操作不重叠。
3. 验证默认焦点、Tab/Shift+Tab；modal 限制背景焦点，非 modal 按自身交互合同验证。
4. 分别关闭按钮、取消、Esc 及适用的遮罩关闭；焦点返回触发器，取消不产生 mutation。
5. 嵌套弹层关闭不误关父层，关闭后残留 portal 不可交互，定位当前实际受控弹层。
6. 提交中按钮状态和重复操作正确；服务端失败保留内容并给出原因，成功后详情与刷新回读一致。
7. 删除确认包含名称及实际影响；引用阻止、允许清理和失败无部分修改分别验证。
8. 仅产品实际提供删除预览/revision/CAS 时验证预览变化冲突；teardown 不充当删除业务断言。

## 13. Menu、Popover、Tooltip 与通知

1. 验证触发器可访问名称，鼠标和适用键盘操作可打开、选择和关闭，禁用项不可执行。
2. 长列表末行及屏幕边缘打开时浮层在视口内、不遮挡必要操作，关闭后焦点合理返回。
3. 菜单项权限、状态条件与真实 API 一致；隐藏按钮之外还需后端权限拒绝证据。
4. Tooltip 只补充说明，不作为唯一可达操作或唯一错误信息；有键盘触发能力时必须验证。
5. 成功通知对应真实持久化结果，错误通知包含操作与具体原因；消失不能替代后端恢复证明。
6. 连续事件或轮询不产生无限重复通知，不遮挡后续重试、取消或编辑入口。

## 14. 多步骤向导与部署参数

1. 检查步骤名、初始步骤、前进/返回及每步校验；非法输入不能绕过必需步骤提交。
2. 前后切换保持同一草稿；取消整个向导不创建半成品，已创建的异步资源按产品合同处理。
3. 快捷/专家模式来回切换，默认值、显式值和 unset 语义保持一致。
4. 按 server `/engines` 字典逐项验证参数类型、枚举、边界、版本可见性，不只覆盖硬编码 vLLM 子集。
5. 更换模型、引擎、spec 或硬件时验证兼容性、模板锁定/偏离、依赖字段更新和失效选择提示。
6. 获取来源由用户明确选择；候选过期须展示真实拒绝，不得静默替换模型/镜像来源。
7. 预览、创建快照与 instance 启动配置一致；分配后端口等差异需有明确合同，测试不能另拼一份命令充当权威。
8. 从提交继续观察 desired→reconcile→agent→workload；recording runtime 只证明派发，真实容器/GPU 效果使用相应 lane。

## 15. YAML、JSON 与命令编辑器

1. 验证初始内容、只读/可编辑状态、格式说明及键盘编辑，编辑器不能吞掉必要导航键。
2. 输入语法错误、schema 错误、未知字段和缺必填字段，验证具体位置/原因及不发送非法 mutation。
3. 格式化、复制、保存和重开后语义一致；敏感字段遵守 secret 合同。
4. 表单与文本模式切换不丢值；无法无损转换时按产品合同提示，不能静默丢弃自定义参数。
5. 手工命令模式禁用应禁用的字段，placement 等仍可编辑项保持有效；切回表单恢复参数来源合同。
6. 验证最终 argv、env、mount 与各 role/rank 的派发配置；预览字符串相同不等于命令实际正确执行。
7. 系统模板只读与克隆后可编辑边界正确，失败不修改原模板。

## 16. 上传、导入、下载与后台进度

1. 验证允许类型、大小边界、空文件、损坏内容及 schema，不支持的格式给具体原因。
2. 对重复导入按合同验证幂等、拒绝或版本变化，不能默认所有重复操作都应成功。
3. 实际传输验证进度、阶段和最终状态；HTTP 接受请求不代表模型/镜像已经可用。
4. 构造部分传输、断线和服务端失败，验证错误、重试及适用的续传，不能把重试计为新的成功资源。
5. 取消后验证任务和临时资源按合同终止/清理；关闭弹窗是否取消任务必须单独验证。
6. 刷新或重新进入后后台任务可回读，进度不会虚假归零或伪装完成。
7. 完成后读取最终文件/目录、内容或 hash，并验证产品实际消费路径可用。
8. 下载/导出检查原始字节、格式、中文编码、列/单位、记录数和筛选一致；失败不能下载 HTML 错误页冒充文件。

## 17. 图表、指标卡与时间线

1. 分别验证 loading、empty、error、数据与陈旧数据，缺失值和真实零值必须可区分。
2. 用已知样本检查查询参数、时间范围、聚合、单位与精度；canvas 存在或截图相似不足以证明数据正确。
3. 实际操作图例、tooltip、时间控件及适用联动，验证对应系列与样本值。
4. 切换节点/GPU/部署或范围后旧响应不覆盖新图表，刷新、follow 与暂停遵循当前选择。
5. GPU 显存、利用率、引擎吞吐和网关请求分别使用其权威来源，不把健康探测请求当成业务调用。
6. 时间线验证事件顺序、状态转移、关联资源与终态；时间接近的历史事件不能代替本次 runId。
7. 无数据、长标签、大数和错误态下检查实际尺寸、单位可见性与无重叠，颜色从主题语义推导。

## 18. 日志查看器与实时流

1. 构造带唯一 marker 的真实日志，验证来源、时间、级别、文本及资源过滤，排除其他资源记录。
2. 验证查询和 live 模式切换、暂停/恢复、清空或返回默认的真实产品行为。
3. 分块到达、多字节字符、空行及长行正确显示；重连后的重复/遗漏按协议合同检查。
4. 搜索、时间范围和分页/增量加载各自验证参数与结果，不能仅检查屏幕出现某个词。
5. 断线、权限失效和服务端失败显示可恢复原因，不永久 loading；关闭页面释放连接与订阅。
6. 下载或复制日志按实际内容验证并脱敏；自动跟随不妨碍用户查看历史位置。
7. 级别下拉框与快捷词标签独立登记：`level=warn` 的通过不能代替 `WARNING` 快捷词参与 `q` 的覆盖。
8. 真实浏览器分别组合文本与单个/多个快捷词，验证组外 AND、组内 OR、短语/引号及准确命中/排除；
   按相互影响关系验证两种输入顺序、移除标签和清空后恢复。只验证字符串或 HTTP 200 不足以通过。
9. 固定 node/instance/source/from/to 与相同 q，真实 search 和 histogram 的命中 ID、total、桶合计
   按相同口径核对；known-hit 返回空必须失败。fixture 同时包含只满足一侧、两侧和均不满足的记录。
10. 单独登记 FTS 语法、快捷词组合与直方图缺口；普通文本＋来源＋级别＋导出 case 不自动包含这些维度。
    ZSTAC-89654 按主规范登记回归要求，规范条目不是产品修复或执行通过的证据。

## 19. Web 终端

1. 按 host/container 目标验证 preflight、权限、kill switch、目标存在性和可诊断拒绝。
2. 建立真实 WS/终端会话，输入安全且有唯一 marker 的命令，观察真实目标返回，不能只检查 xterm canvas。
3. 验证 UTF-8 跨帧、连续输出、键盘输入与窗口 resize，字符不乱码且目标终端尺寸正确。
4. 验证命令退出、主动关闭、断线和适用恢复；关闭后会话与资源释放。
5. 验证并发上限和空闲超时；明确拒绝或结束状态，没有遗留不可见会话。
6. 检查会话审计的主体、目标和结果，报告不得暴露凭据或不必要的终端内容。

## 20. Playground、Markdown 与 HTML 预览

1. 按 deployment snapshot 声明的每个可用 operation 验证真实输入、默认值、校验和 renderer，不能全部退化成打开 chat。
2. 对适用的 chat/embeddings/rerank/媒体操作分别验证 method、path、body 和最小业务输出语义。
3. SSE 分块、结束事件、错误、中途取消和 usage 分别断言；显示部分文字不代表流正常完成。
4. 验证附件类型/大小/移除及媒体资源生命周期，失败重试不重复发送陈旧附件。
5. 对比运行和页面切换按产品合同保持生成；刷新/关闭导致中断时正确标记，不伪装完成。
6. 验证历史会话按账户隔离和实际保留规则；重新登录不能看到另一账户本地历史。
7. Markdown 的代码、链接、复制与错误展示正确；HTML 预览使用 opaque origin 和规定 CSP，不开放同源权限。
8. 默认禁止网络与显式允许网络分别验证；允许网络不能解除 sandbox 的 origin 隔离。
9. 推理 Key 的公开 `/v1/*` 调用与登录会话的 `/api/v1/playground/v1/*` 分别验收，不相互替代。

## 21. 复制按钮、代码块与接入片段

1. 通过真实复制交互读取剪贴板，逐字对比展示值、复制值与权威配置；验证适用的 HTTP fallback。
2. URL 明确检查 scheme、host、port、path，不能混入监听地址 `0.0.0.0`、内部地址或重复 API 前缀。
3. 在同一可访问网络边界执行复制出的地址/命令，不能改写 host 或 path 后再声称复制内容可用。
4. 检查真实业务响应和可解析结构，HTTP 200 的 SPA HTML 不能算 API 成功。
5. 配置片段由权威 parser 或目标程序消费并验证结果；secret 仅安全消费，不进入命令输出或测试报告。
6. 权限拒绝、剪贴板不可用或复制失败给出恢复入口；仅显示“已复制”不能作为成功证据。

## 22. 导航、Tabs、权限与语言

1. 每个实际页面入口与深链分别进入，检查标题、选中态、目标组件及刷新后位置。
2. 浏览器前进/后退、Tabs 切换与 URL 参数按合同保留状态，不能出现页面内容和导航选中态不一致。
3. admin/user 分别验证菜单、按钮和直接 API 权限；GPUWorks 不套用 Router 的组织/IAM 权限模型。
4. 登录失效与重新认证验证目的页面和可恢复草稿；后台轮询不能被当成人类活动无限续期。
5. zh/en 分别检查导航、首屏、表单、错误、空态及实际动态文本，内部字段名不能代替翻译。
6. 真实键盘操作验证 focus-visible；颜色、间距和禁用态使用浏览器 computed style 与主题 token 语义比较。
7. 新窗口、外链与下载按产品合同执行，错误链接/深链不能被 SPA fallback 的 200 掩盖。

## 23. AI 助手与工具结果

1. 无 LLM 配置时产品核心流程仍可用，助手显示准确配置状态而非拖垮页面。
2. 验证问题输入、发送中、流式回答、取消、失败和重试，单次用户操作不重复调用。
3. 工具结果关联实际资源与权限，已知估算输入对应确定性计算结果，不能仅断言回答文字存在。
4. 只读工具不能越权写资源、执行任意命令或读取受限 secret/终端内容，绕过 UI 的请求也须拒绝。
5. 回答、Markdown、链接和工具错误遵守不可信输出与脱敏合同；缺数据不能虚构成功操作。
